# Medical-Health-Insurance-Prediction-Based-on-Indian-Health-care
This Mini Project helps users to calculate their medical health insurance premium based on 2025 Indian insurance companies database.
The system is designed as a lightweight, practical prototype with real-world relevance. It reduces manual errors, saves time, and enhances transparency. Customers can understand how their personal and health information affects premium calculations, while administrators can manage and analyze data effectively.
