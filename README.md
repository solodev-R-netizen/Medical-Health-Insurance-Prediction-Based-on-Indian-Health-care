# Medical-Health-Insurance-Prediction-Based-on-Indian-Health-care

The system is designed as a lightweight, practical prototype with real-world relevance. It reduces manual errors, saves time, and enhances transparency. Customers can understand how their personal and health information affects premium calculations, while administrators can manage and analyze data effectively. SOFTWARE REQUIREMENTS
Software requirements include the programming languages, frameworks, libraries, and tools needed to develop and run the system:
Operating system: Windows 10 or Linux-based systems.
Backend framework: Python Flask for lightweight and efficient web development.
Database: SQLite for structured storage of customer, policy, and premium data.
Frontend technologies: HTML, CSS, JavaScript, and Materialize for a responsive and clean interface.
Web browsers: Google Chrome, Firefox, or Edge for accessing the system.
Optional libraries: Chart.js or similar for visual trend representation.
IDE or text editors: VS Code, PyCharm, or other suitable development environments.
